#  Blinkit Sales Analysis Dashboard | Power BI

##  Project Overview

This project is an interactive **Business Intelligence dashboard developed using Microsoft Power BI** to analyze Blinkit's sales performance across different outlet types, outlet sizes, locations, product categories, and establishment years.

The dashboard transforms raw sales data into meaningful business insights through interactive KPIs, charts, slicers, and visualizations.

It is designed to help business stakeholders quickly understand overall sales performance, product contribution, outlet performance, customer ratings, and other important business metrics.

---

##  Project Objectives

The primary objectives of this project are to:

- Analyze overall sales performance.
- Monitor important business KPIs.
- Compare sales across different outlet types.
- Analyze sales based on outlet location tiers.
- Understand the contribution of different product categories.
- Compare Low Fat and Regular products.
- Analyze outlet performance based on outlet size.
- Study sales trends based on outlet establishment year.
- Provide an interactive dashboard for business decision-making.

#  Important Measures

The dashboard uses business measures such as:

### Total Sales

```DAX
Total Sales = SUM(Data[Sales])
```

### Average Sales

```DAX
Avg Sales = AVERAGE(Data[Sales])
```

### Number of Items

```DAX
No of Items = COUNTROWS(Data)
```

### Average Rating

```DAX
Avg Rating = AVERAGE(Data[Rating])
```

> The exact table and column names may differ depending on the dataset used in the Power BI project.
